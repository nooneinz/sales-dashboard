# لوحة تحليل المبيعات

لوحة عربية لتحليل ملفات المبيعات (CSV) تعمل بالكامل في المتصفح، ولا تُرسل البيانات إلى أي خادم.

**الرابط:** https://nooneinz.github.io/sales-dashboard/

## الاستخدام

1. افتح الرابط.
2. ارفع ملف CSV فيه الأعمدة: `date, product, category, quantity, price` (أو بالعربي: التاريخ، المنتج، الفئة، الكمية، السعر).
3. للتجربة حمّل الملف [sample-sales.csv](sample-sales.csv) (200 صف تجريبي).

## المزايا

- مؤشرات: إجمالي المبيعات، عدد الطلبات، أفضل منتج، متوسط قيمة الطلب (بالريال العماني)
- رسم أعمدة للمبيعات حسب الشهر، ورسم حلقي حسب الفئة مع النسب
- فلتر حسب الفئة والفترة الزمنية
- تبديل الأرقام بين اللاتينية والعربية الهندية
- يدعم الجوال والوضع الداكن

مبني بـ HTML و CSS و JavaScript، مع Chart.js و PapaParse.
